# 井字過三關 (Tic-Tac-Toe) - 純靜態版

這是一個使用原生 JavaScript、HTML5 和 CSS 實現的經典井字過三關網頁遊戲。此專案是一個**完全獨立的靜態網站**，無需任何構建步驟或伺服器端依賴，支援**本地雙人**和**P2P 線上對戰**兩種模式。

## ✨ 功能

-   **雙遊戲模式**:
    -   **本地雙人對戰**: 在同一台電腦上與朋友對戰。
    -   **線上 P2P 對戰**: 透過 WebRTC (PeerJS) 與遠端玩家直接連線對戰。
-   經典 3x3 遊戲棋盤
-   自動檢測獲勝、失敗或平手
-   響應式設計
-   一鍵重設遊戲

## 🛠️ 技術棧

-   **前端:**
    -   HTML5, CSS3, JavaScript (ES6+ 模組化)
    -   **PeerJS (透過 CDN)**: 用於簡化 WebRTC P2P 通訊。

## 🚀 如何運行

這個專案是零依賴的，您不需要安裝任何工具（如 Node.js 或 Docker）。

### 方法 1: 直接在本地打開 (可能受限)

1.  下載並解壓縮所有檔案。
2.  在您的網頁瀏覽器中直接打開 `index.html` 檔案。

**注意**: 由於瀏覽器的安全策略 (CORS)，直接以 `file://` 協議打開 `index.html` 可能會限制 ES6 模組的載入。如果遇到問題，請使用方法 2。

### 方法 2: 使用任何 Web 伺服器 (推薦)

這是最可靠的運行方式。

1.  **將所有檔案上傳**: 將此專案的所有檔案 (`index.html`、`css/` 目錄、`js/` 目錄) 上傳到任何支援靜態檔案託管的 Web 伺服器或服務中，例如：
    -   GitHub Pages
    -   Netlify / Vercel
    -   您自己的 Apache / Nginx 伺服器
    -   任何虛擬主機的 `public_html` 或 `www` 目錄
2.  **訪問 URL**: 透過伺服器提供的 URL 訪問 `index.html`。

### 🕹️ 如何進行線上對戰

1.  **啟動應用程式**: 將專案部署到一個公開的 Web 伺服器上，並讓兩位玩家都訪問該 URL。
2.  **玩家 A**:
    -   在彈出視窗中選擇 "🌐 線上對戰"。
    -   等待 "你的ID" 載入完成，並將該 ID 複製後發送給玩家 B。
3.  **玩家 B**:
    -   在彈出視窗中選擇 "🌐 線上對戰"。
    -   將玩家 A 的 ID 貼到 "輸入對手ID" 的輸入框中。
    -   點擊 "連線"。
4.  連線成功後，遊戲將自動開始。玩家 A (發起連線者) 為 'X'，玩家 B 為 'O'。

## 🏛️ 架構設計

本專案採用了模組化的架構，將應用程式邏輯分為多個獨立的 JS 模組，以遵循**單一職責原則**：

-   **`Store.js`**: 負責所有狀態管理。
-   **`UI.js`**: 負責所有 DOM 操作和事件監聽。
-   **`P2P.js`**: 封裝所有 PeerJS 網路通訊邏輯。
-   **`Game.js`**: 作為協調者，串連 UI、狀態和網路邏輯。
-   **`index.js`**: 應用程式的進入點。

這種分離使得程式碼高度解耦，易於理解和維護。
